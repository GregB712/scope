#### 2.4 Top-severity Node-RED flaw under active attack
- **Category:** Cybersecurity
- **Importance:** 8/10
- **Event date:** Exploitation began ~2026-10-30; warning 2026-11-02; detailed 2026-11-03.
- **What happened:** A security flaw labelled CVE-2026-58115 carries the maximum danger score of 10.0. It affects Node-RED, a popular tool for connecting devices and automating tasks, including Siemens SIMATIC IoT2050 industrial gateways running their software before version V4.3.4.1, and any Node-RED setup left online without a login requirement. Because the admin interface has no password check, attackers on the internet can run commands on the machine. Researchers (VulnCheck) report real attacks that install malware and hidden backdoors.
- **Why it matters:** Node-RED is used in factories, building systems and "internet of things" setups. A flaw this severe, already being exploited, can let attackers seize control of industrial equipment.
- **Implications:** Any exposed, password-less Node-RED is at immediate risk. Fixes exist and should be applied now.
- **What to monitor next:** Whether attacks spread to more industrial sites; follow-on advisories from Siemens and national cyber agencies.
- **Fix:** Update Siemens systems to Industrial OS V4.3.4.1; turn on the `adminAuth` login setting; keep the admin port (1880) off the public internet.
- **Sources:** [SecurityOnline – CVE-2026-58115](https://securityonline.info/node-red-rce-vulnerability-cve-2026-58115/)
